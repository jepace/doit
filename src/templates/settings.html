How to connect an assistant

MCP server URL: {{ base_url }}/mcp — authenticate with the header Authorization: Bearer {{ tok }}.

Claude Code

claude mcp add --transport http doit {{ base_url }}/mcp --header "Authorization: Bearer {{ tok }}"

Gemini CLI — in ~/.gemini/settings.json:

{"mcpServers": {"doit": {
  "httpUrl": "{{ base_url }}/mcp",
  "headers": {"Authorization": "Bearer {{ tok }}"}}}}

Claude Desktop — in claude_desktop_config.json (needs Node.js):

{"mcpServers": {"doit": {
  "command": "npx",
  "args": ["-y", "mcp-remote", "{{ base_url }}/mcp", "--header", "Authorization:${DOIT_AUTH}"],
  "env": {"DOIT_AUTH": "Bearer {{ tok }}"}}}}

Anything else — plain REST, e.g.

curl -H "Authorization: Bearer {{ tok }}" "{{ base_url }}/api/v1/tasks?due_before=$(date +%F)"

Treat a token like a password: anyone holding it can act on your list within its permissions. Revoke it here if it leaks.
